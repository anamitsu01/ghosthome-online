# ゴーストホーム

屋敷に潜む幽霊1人と、それを探す人間3人の非対称かくれんぼ(2〜4人、オンライン)。幽霊は3つの品を集めて完全復活を目指し、人間は潜伏場所を探索して幽霊を退治する。

## 動かし方

```bash
npm install
npm run dev        # http://localhost:3000
```

ホームの「動作確認(テスト相手と)」(または部屋コード `ZZZZZ`)で、サイコロを振って適当に動くだけのテスト相手と1人で動作確認できます。ロビーで誰を幽霊にするか指名できます。

```bash
npm run simulate   # ルールの確認 + テスト相手同士で500局
npm run build && npm start
```

## ルールの実装

- 屋敷のデータ(部屋・潜伏場所・探索コスト・出入口・幽霊の壁抜け・見取り図の座標)は `lib/map.ts`。
- アイテムとキャラクターは `lib/catalog.ts`。
- 手番の進行・判定・情報の出し分けは `lib/gameEngine.ts`。サーバーが全情報を持ち、`viewFor` で幽霊側・人間側それぞれに見えるものだけを送る(幽霊の位置は完全復活まで人間に送らない、人間の持ち物は幽霊に送らない)。

## 構成

Next.js + Socket.IO のカスタムサーバー(`server.ts`)。部屋はメモリ上に保持。Dockerfile あり(Railway でそのまま動く)。
